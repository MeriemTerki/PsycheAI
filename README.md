# LLM-Powered Voice-Driven Mental Wellness Assessment with Gaze and Emotion Analysis
 
PsycheAI is a mental wellness assessment app. The user talks with a voice assistant while the webcam is used to track their gaze and facial emotions. When the session ends, everything is combined into one report.
 
It is a research project and is not meant to diagnose anything or replace a professional.
 
[Demo video](https://www.youtube.com/watch?v=MlXCU632cXc&t=126s) | [Full report (PDF)](PsycheAI_Report.pdf)
 
## Architecture
 
![PsycheAI architecture](docs/architecture.png)
 
The system is made of three pipelines that run at the same time during a session:
 
- **Emotion pipeline:** a YOLOv8 model detects facial emotions from the video. The results are saved as a CSV of metrics, embedded with Cohere, and summarized by a Groq LLM into an emotion report.
- **Gaze pipeline:** MediaPipe Face Mesh finds the eye landmarks, and we compute gaze features from them. Same as above, the metrics go to a CSV, then Cohere, then Groq, which writes a gaze analysis report.
- **Audio pipeline:** the microphone is streamed to Deepgram for real-time transcription. The reply is generated by the LLM, turned into speech, and played with PyAudio. The whole conversation is saved as a transcript.
At the end of the session, the two reports and the transcript are embedded with Cohere and stored in Pinecone. The LLM then uses them to write the final report.
 
## Features
 
- **Conversational AI Assessment**: talks with the user in an empathetic way to understand how they are doing.
- **Real-time Gaze Tracking**: looks at eye movements to infer attention, focus and cognitive state.
- **Real-time Emotion Recognition**: detects facial expressions to follow the user's emotional state.
- **Assessment Report**: combines voice, gaze and emotion data into one report with personalized recommendations.
- **Supportive, not clinical**: the assistant is built to be supportive and avoids giving clinical diagnoses.
### APIs
 
The project is split into small services:
 
- **Gaze Tracking Service**: eye tracking analysis (`http://127.0.0.1:8001`)
- **Emotion Recognition Service**: facial emotion detection (`http://127.0.0.1:8000`)
- **Voice Chat/TTS Service**: conversation and text-to-speech (`http://127.0.0.1:8002`)
- **Main API**: starts sessions and builds the final report (`http://127.0.0.1:8003`)
## Setup and Installation
 
### Prerequisites
 
- Node.js (with npm or yarn)
- Python 3.9+
- pip
- A webcam and a microphone
### 1. Clone the repository
 
```
git clone https://github.com/MeriemTerki/PsycheAI.git
cd PsycheAI
```
 
### 2. Backend Setup
 
```
cd backend
pip install -r requirements.txt
```
 
Create a `.env` file in `backend/app` with the following:
 
```
GROQ_API_KEY="your_groq_api_key_here"
DEEPGRAM_API_KEY="your_deepgram_api_key_here"
PINECONE_API_KEY="your_pinecone_api_key_here"
PINECONE_INDEX_NAME=ai-agent
COHERE_API_KEY="your_cohere_api_key_here"
GAZE_CAPTURE_URL=http://127.0.0.1:8001/capture-eye-tracking
GAZE_REPORT_URL=http://127.0.0.1:8001/generate-eye-tracking-report
EMOTION_API_URL=http://127.0.0.1:8000/analyze-live-emotion
CHAT_API_URL=http://127.0.0.1:8002/chat
TRANSCRIPT_GET_URL=http://127.0.0.1:8002/transcript
SESSION_API_URL=http://127.0.0.1:8003/start-session
REPORT_GET_URL=http://127.0.0.1:8003/get-report
```
 
If you run the services on different ports, change the URLs accordingly.
 
Run the FastAPI backend:
 
```
uvicorn app.main:app --reload --port 8003
```
 
The gaze, emotion and voice chat/TTS services also need to be running on their ports (8001, 8000 and 8002).
 
### 3. Frontend Setup
 
In a new terminal:
 
```
cd frontend
npm install
npm start
```
 
The app opens at `http://localhost:3000`.
 
## Usage
 
1. Make sure all the backend services are running.
2. Open the frontend in your browser.
3. Click "Start Assessment" to begin the conversation.
4. Allow webcam and microphone access when asked.
5. Talk with the AI assistant.
6. Click "End Session" to generate the report.
